```
termsuite-api/
  treetagger/
    tree-tagger-linux-3.2.4.tar.gz
    tagger-scripts.tar.gz
    models/
      spanish-utf8.par.gz

      german-utf8.par.gz
      portuguese-utf8.par.gz
      italian-utf8.par.gz
      # ... más idiomas según necesites
```

## Instrucciones de Descarga

### Opción 1: Navegador
1. Abre cada URL en tu navegador
2. Guarda el archivo en la ubicación indicada

### Opción 2: wget (Linux/Mac/WSL)
```bash
cd termsuite-api/treetagger

# Descargar binarios
wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/tree-tagger-linux-3.2.4.tar.gz
wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/tagger-scripts.tar.gz

# Descargar modelos principales (recomendado)
cd models
wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/spanish-utf8.par.gz
wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/english-utf8.par.gz
wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/french-utf8.par.gz
wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/german-utf8.par.gz
wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/portuguese-utf8.par.gz
wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/italian-utf8.par.gz

# Opcional: Descargar más idiomas
# wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/dutch-utf8.par.gz
# wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/russian-utf8.par.gz
# wget https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/polish-utf8.par.gz
# ... (ver lista completa arriba)

cd ..
```

### Opción 3: curl (Linux/Mac/WSL)
```bash
cd termsuite-api/treetagger

# Descargar binarios
curl -O https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/tree-tagger-linux-3.2.4.tar.gz
curl -O https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/tagger-scripts.tar.gz

# Descargar modelos
cd models
curl -O https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/spanish-utf8.par.gz
curl -O https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/english-utf8.par.gz
curl -O https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/french-utf8.par.gz
curl -O https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/german-utf8.par.gz
cd ..
```

### Opción 4: PowerShell (Windows)
```powershell
cd termsuite-api\treetagger

# Descargar binarios
Invoke-WebRequest -Uri "https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/tree-tagger-linux-3.2.4.tar.gz" -OutFile "tree-tagger-linux-3.2.4.tar.gz"
Invoke-WebRequest -Uri "https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/tagger-scripts.tar.gz" -OutFile "tagger-scripts.tar.gz"

# Descargar modelos
cd models
Invoke-WebRequest -Uri "https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/spanish-utf8.par.gz" -OutFile "spanish-utf8.par.gz"
Invoke-WebRequest -Uri "https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/english-utf8.par.gz" -OutFile "english-utf8.par.gz"
Invoke-WebRequest -Uri "https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/french-utf8.par.gz" -OutFile "french-utf8.par.gz"
Invoke-WebRequest -Uri "https://www.cis.uni-muenchen.de/~schmid/tools/TreeTagger/data/german-utf8.par.gz" -OutFile "german-utf8.par.gz"
cd ..
```

## Siguiente Paso

Una vez descargados todos los archivos:

```bash
cd termsuite-api
docker-compose down
docker-compose build
docker-compose up -d
```

El Dockerfile detectará automáticamente los archivos y los instalará.
